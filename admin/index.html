Sign in with a GitHub token

This page edits your storefront's text, colors and layout. It has no password of its own. Instead you give it a small, locked-down GitHub key that can only touch this one repository. You only do this once per device.

  1. Open GitHub's token page (sign in as yesirfa-sudo if asked):
    Create the token on GitHub → Same page as github.com/settings/personal-access-tokens/new. By hand: your profile picture → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Token name: wGB admin. Expiration: pick 90 days (shorter is safer; when it expires just make a new one the same way).
  3. Resource owner: yesirfa-sudo.
  4. Repository access: choose Only select repositories, then pick wgb-site and nothing else.
  5. Permissions: click Add permissions (or open Repository permissions), find Contents and set it to Read and write. Leave everything else as No access. (GitHub adds read-only "Metadata" by itself. That's fine.)
  6. Click Generate token, then copy the token (it starts with github_pat_). GitHub only shows it once.
  7. Paste it below and press Connect.

Is this safe? The token is saved only in this browser (localStorage), is sent only to api.github.com, and is never written into the website's files. Anyone who opens this page without the token can look at the screen but can't change anything. To lock a device out, press Sign out here, or delete the token any time at github.com/settings/personal-access-tokens. Use the same steps on your phone and your PC (each device needs its own paste).
